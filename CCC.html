1. Finding the Shortest Path GREEDY
⏱ Time: O((V+E) log V) • Space: O(V) • Uses priority queue!

Dijkstra's algorithm finds the cheapest route between cities. It's greedy - always picks the closest unvisited city first! Pretty smart, right? 🤓

2. What to Pack? (Knapsack) DYNAMIC
⏱ Time: O(n×W) • Space: O(n×W) • Bottom-up table magic!

The 0/1 knapsack problem! Pick the best stuff for your bag without going over the weight limit. Uses a 2D table to remember solutions. 🎒

3. Making Change (Coins) DYNAMIC
⏱ Time: O(amount × coins) • Space: O(amount) • DP array ftw!

Find the minimum number of coins needed for any rupee amount. Tries every coin at each step and picks the best combo! 💸

4. Planning My Day (Activities) GREEDY
⏱ Time: O(n log n) • Space: O(n) • Sort by finish time!

Activity selection picks the max non-overlapping activities. The greedy trick: always choose the one that ends earliest! Works every time. 📆

🎯 What's This All About?

AlgoVoyage is my travel-themed algorithm notebook! 📓 Each section shows a different classic algorithm in action. It's like learning CS while planning a trip!

🗺️ Dijkstra's Path

Greedy shortest path finder using a min-heap. Connects 14 Indian cities with real-ish distances. Always picks the closest unvisited node!

🎒 Knapsack Packing

Bottom-up dynamic programming to maximize value in limited space. Classic optimization - O(nW) complexity with a 2D table!

💰 Coin Change

DP array approach for minimum coins. Works with Indian rupee denominations (₹1 to ₹500). Builds up from smaller amounts!

📅 Activity Planner

Greedy interval scheduling! Sort by finish time, pick non-overlapping activities. Provably gives the optimal solution every time!
