# ✈️ AlgoVoyage — Travel Algorithm Notebook

AlgoVoyage is an interactive, travel-themed web application that visualizes classic algorithms in a fun and intuitive way. It combines computer science concepts with real-world travel scenarios to make learning engaging and easy.

---

## 🌟 Features

### 🗺️ Shortest Path (Dijkstra’s Algorithm)

* Finds the shortest route between cities
* Uses a greedy approach with a priority queue
* Displays path, distance, and step-by-step breakdown

### 🎒 Knapsack Problem (0/1 Knapsack)

* Selects optimal items within a weight limit
* Uses dynamic programming (2D table)
* Shows selected items, total weight, and value

### 💰 Coin Change Problem

* Calculates minimum coins required for a given amount
* Uses dynamic programming (1D array)
* Supports Indian currency denominations

### 📅 Activity Selection

* Selects maximum non-overlapping activities
* Uses greedy strategy (sorted by finish time)
* Visual timeline for schedule planning
